# OpenCode 汉化版

## 一条命令安装

### 方式一：PowerShell 安装 (推荐 Windows 用户)

```powershell
iwr https://raw.githubusercontent.com/ev71h5n1-wq/opencode-zh/main/install-zh.ps1 | iex
```

### 方式二：npm 安装

```bash
npm i -g opencode-zh
```

### 方式三：Bash 安装 (Git Bash / WSL)

```bash
curl -fsSL https://raw.githubusercontent.com/ev71h5n1-wq/opencode-zh/main/install | bash
```

安装完成后，在任意目录输入 `opencode-zh` 即可启动。

---

## 手动启动（开发模式）

项目根目录已创建 `opencode-zh.bat`，复制此文件到 `C:\Windows\System32` 或添加到 PATH，即可在任意目录输入 `opencode-zh` 启动汉化版。

或者在 PowerShell 中运行：
```powershell
F:\AI-Tools\opencode\opencode-dev\opencode-zh.bat
```

## 问题原因

终端输入 `opencode` 报错 "无法将'opencode'项识别为 cmdlet..." 是因为项目依赖未安装，`opencode` 命令尚未注册到系统中。

## 环境要求

- [Bun](https://bun.sh) 运行时 (项目使用 bun@1.3.9)

## 启动步骤

### 1. 安装 Bun (如未安装)

```powershell
# Windows PowerShell
powershell -c "irm bun.sh/install.ps1 | iex"
```

### 2. 安装项目依赖

在项目根目录执行：

```powershell
cd F:\AI-Tools\opencode\opencode-dev
bun install
```

### 3. 启动 OpenCode CLI

#### 方式一：开发模式（推荐）

```powershell
bun run dev
```

#### 方式二：通过 bin 目录直接运行

```powershell
./packages/opencode/bin/opencode
```

#### 方式三：全局安装后使用

```powershell
# 进入 opencode 包目录
cd packages/opencode

# 链接到全局
bun link

# 之后就可以在任何地方使用 opencode 命令
opencode
```

### 4. 构建生产版本

```powershell
bun run --cwd packages/opencode build
```

## Web 界面启动

如需启动 Web 版界面：

```powershell
bun run dev:web
```

然后在浏览器访问 `http://localhost:3000`

## 桌面应用启动

```powershell
bun run dev:desktop
```

## 在任意目录启动汉化版（详细）

### 方式一：使用批处理文件（最简单）

项目根目录已创建 `opencode-zh.bat`，你可以：

1. **直接运行** - 在项目根目录双击 `opencode-zh.bat`

2. **全局使用** - 将 `F:\AI-Tools\opencode\opencode-dev` 添加到系统 PATH，然后在任意目录输入：
   ```powershell
   opencode-zh
   ```

3. **永久全局命令** - 将 `opencode-zh.bat` 复制到系统目录：
   ```powershell
   copy "F:\AI-Tools\opencode\opencode-dev\项目文件\opencode-zh.bat" "C:\Windows\System32\opencode-zh.bat"
   ```
   然后任意目录输入 `opencode-zh` 即可启动

   > **原理说明**：脚本使用 `--dir %CD%` 将当前目录传递给 opencode，让 opencode 在该目录下工作

### 方式二：PowerShell 脚本

项目根目录已创建 `opencode-zh.ps1`：

```powershell
# OpenCode 汉化版启动脚本
$Cwd = "F:\AI-Tools\opencode\opencode-dev\packages\opencode"
$UserDir = Get-Location
$Bun = "C:\Users\kery\.bun\bin\bun.exe"

& $Bun run --cwd $Cwd --conditions=browser src/index.ts --dir $UserDir @args
```

使用方式：
```powershell
# 在任何项目目录运行
F:\AI-Tools\opencode\opencode-dev\opencode-zh.ps1
```

> **原理说明**：`--cwd` 指向 opencode 安装目录，`--dir` 传递用户当前目录给 opencode

### 方式三：创建 cmd 全局命令

```powershell
# 创建全局命令文件
$cmdContent = '@echo off' + "`n" + 'C:\Users\kery\.bun\bin\bun.exe run --cwd F:\AI-Tools\opencode\opencode-dev\packages\opencode --conditions=browser src/index.ts --dir %CD% %*'
$cmdContent | Out-File -FilePath "$env:LOCALAPPDATA\Microsoft\WindowsApps\opencode-zh.cmd" -Encoding ASCII
```

然后任意目录输入 `opencode-zh` 即可启动，会自动使用当前目录作为项目目录

> **原理说明**：`--cwd` 指向 opencode 安装目录（为了找到 src/index.ts），`--dir %CD%` 告诉 opencode 切换到用户当前目录工作

# 在其他电脑使用汉化版

## 必需拷贝的文件

### 1. 整个项目源代码（已汉化）
```
opencode-dev/
├── packages/              # 核心代码（已汉化）
│   ├── opencode/          # CLI 主程序
│   ├── app/               # Web 界面
│   └── ...其他包
├── node_modules/          # 依赖（已安装）
├── opencode-zh.bat        # 启动脚本
└── bun.lock              # 锁定文件
```

### 2. Bun 运行时
```
C:\Users\kery\.bun\bin\bun.exe
```

## 快速打包步骤

在 PowerShell 中执行：

```powershell
# 1. 创建便携包目录
mkdir "F:\OpenCode-汉化版"
mkdir "F:\OpenCode-汉化版\bun"

# 2. 拷贝项目（排除 .git 等大文件）
robocopy "F:\AI-Tools\opencode\opencode-dev" "F:\OpenCode-汉化版\opencode-dev" /E /XD .git node_modules\.cache /R:0 /W:0

# 3. 拷贝 bun
copy "C:\Users\kery\.bun\bin\bun.exe" "F:\OpenCode-汉化版\bun\"

# 4. 创建通用启动脚本
$batContent = @'
@echo off
chcp 65001 >nul
%~dp0bun\bun.exe run --cwd %~dp0opencode-dev\packages\opencode --conditions=browser src/index.ts %*
'@
$batContent | Out-File -FilePath "F:\OpenCode-汉化版\启动汉化版.bat" -Encoding utf8

# 5. 创建说明文件
$readme = @'
# OpenCode 汉化版

## 启动方式
双击运行：启动汉化版.bat

## 在其他电脑使用
将整个 OpenCode-汉化版 文件夹复制到任意位置
双击 启动汉化版.bat 即可使用

## 注意事项
- 需要 Windows 10/11 64位系统
- 不需要额外安装任何依赖
- 所有文件都在此文件夹中，便携免安装
'@
$readme | Out-File -FilePath "F:\OpenCode-汉化版\使用说明.txt" -Encoding utf8
```

## 在其他电脑使用步骤

1. **复制文件夹** - 将 `OpenCode-汉化版` 文件夹复制到目标电脑（U盘、移动硬盘、网盘等）
2. **双击运行** - 双击 `启动汉化版.bat` 即可运行汉化版 OpenCode

## 最小化方案（精简版）

如果只需要 CLI 版本（不需要 Web 和 Desktop）：

```powershell
# 创建精简版目录
mkdir "F:\OpenCode-精简版"

# 只保留必要文件
robocopy "F:\AI-Tools\opencode\opencode-dev\packages\opencode" "F:\OpenCode-精简版\opencode" /E /XD .git /R:0 /W:0
robocopy "F:\AI-Tools\opencode\opencode-dev\node_modules" "F:\OpenCode-精简版\node_modules" /E /R:0 /W:0
copy "C:\Users\kery\.bun\bin\bun.exe" "F:\OpenCode-精简版\"
copy "F:\AI-Tools\opencode\opencode-dev\bun.lock" "F:\OpenCode-精简版\"
copy "F:\AI-Tools\opencode\opencode-dev\package.json" "F:\OpenCode-精简版\"

# 创建启动脚本
$batContent = @'
@echo off
chcp 65001 >nul
%~dp0bun.exe run --cwd %~dp0opencode\packages\opencode --conditions=browser src/index.ts %*
'@
$batContent | Out-File -FilePath "F:\OpenCode-精简版\启动.bat" -Encoding utf8
```

这样整个文件夹大约 **200-300MB**，可以放在 U 盘里随身带走，在任何 Windows 电脑上都能即插即用！
